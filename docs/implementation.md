# 场景、交战与验证说明

本页保留项目的实体结构、交战规则、物理效果和各项验证细节。数值为内置初始默认值；完整字段说明见 [游戏数值配置说明](../config/README.md)。运行方式和操作按键见 [项目首页](../README.md)。

## 场景

- `scenes/main.tscn`：组合草坪场地、植物、人物、灯光和备用模型查看相机。
- `scenes/characters/crazy_dave.tscn`：独立的疯狂戴夫实体，包含锅帽、胡子、白色上衣、蓝色裤子、碰撞体和腰部相机。
- `scenes/environment/dave_house.tscn` / `scripts/dave_house.gd`：独立房屋实体，根据启动配置搭建屋顶、墙体、门洞、自动门、室内家具和可行走地面；Godot 编辑器中也能预览。
- `scenes/enemies/zombie.tscn`：独立僵尸实体，包含灰绿色皮肤、凸出的眼睛、稀疏头发、缺牙、棕色外套、红领带、破旧牛仔裤、前伸手臂和碰撞体。各部位可以单独编辑。
- `scenes/enemies/conehead_zombie.tscn`：独立路障僵尸实体，继承普通僵尸，生命 570，头顶橙色路障帽带白色反光条。
- `scenes/enemies/buckethead_zombie.tscn`：独立铁桶僵尸实体，继承普通僵尸，默认生命 1370；倒扣的金属桶有卷边、内衬、提手及磨痕。
- `scenes/enemies/pole_vaulting_zombie.tscn` / `scripts/pole_vaulting_zombie.gd`：独立撑杆僵尸实体，继承普通僵尸，默认生命 500；红色运动背心和运动鞋、灰色短裤、蓝色头带及黄色发束；单手弯臂举起 3.6 单位长杆，杆水平放在头顶、沿行进方向延伸，另一只手垂下，前倾身体和弯腿保持跑步姿势。接近同一路径第一株植物时撑杆跳跃一次。
- `scripts/crazy_dave.gd`：基础人物移动、转向、腰部视角与重置逻辑。
- `scenes/plants/peashooter.tscn`：可独立复用的植物，包含头部、炮口、眼睛、茎和四片叶子。
- `scenes/plants/repeater.tscn` / `scripts/repeater.gd`：独立的双发射手实体，继承普通豌豆射手的模型结构、目标检测与豌豆逻辑，使用深绿色头部、眉毛与后侧叶冠。每轮从同一炮口连续发射两颗豌豆。
- `scenes/plants/threepeater.tscn` / `scripts/threepeater.gd`：独立三线射手实体，拥有三个完整头部、三个炮口和共同的分叉茎。检测自身及左右相邻路径的陆地僵尸，每轮同时向三条路径各发射一颗豌豆。
- `scenes/plants/gatling_pea.tscn` / `scripts/gatling_pea.gd`：独立机枪射手实体，带橄榄绿头盔、帽带和四管炮口，每轮依次从四个炮管水平发射四颗豌豆，仅检测自己所在路径的陆地僵尸。
- `scenes/plants/snow_pea.tscn` / `scripts/snow_pea.gd`：独立寒冰射手实体，使用冰蓝色头部、茎叶和后侧冰晶冠，向自己所在路径发射寒冰豌豆，共用普通植物的目标检测与后坐力。
- `scenes/plants/wall_nut.tscn` / `scripts/wall_nut.gd`：独立坚果实体，位于第 5 行第 8 列，包含金棕色坚果壳、凹凸纹路、眼睛和嘴，以及不阻挡友方豌豆的防御植物碰撞体。
- `scenes/terrain/grass_tile.tscn`：单格草坪实体，包含土层、草皮、草簇、小石头与地面碰撞体，不包含植物。
- `scenes/terrain/lawn_grid.tscn`：由 45 个 `grass_tile.tscn` 实例组成的场地，每格都能在编辑器中独立选择和调整。
- `scripts/grass_tile.gd`：草坪格的坐标与深浅颜色设置，颜色在编辑器中也能预览。
- `scripts/lawn_grid.gd`：行列坐标、格子查询与世界坐标转换。
- `scripts/peashooter.gd`：同一防线的陆地僵尸检测、每 1.5 秒发射豌豆、待机摆动和五种豌豆植物共用的开火后坐力。
- `scenes/projectiles/pea.tscn` / `scripts/pea_projectile.gd`：独立豌豆实体，水平飞行，触碰僵尸造成一次 20 点伤害后消失。
- `scenes/projectiles/snow_pea.tscn`：继承普通豌豆的冰蓝色弹体，保持 20 点伤害，并对命中的僵尸施加限时减速。
- `scripts/zombie.gd`：四种僵尸共用的行走、寒冰减速与独立冷色外观、受击、血量阈值、路障及铁桶脱落、随机断手、飞头和物理尸体逻辑。
- `scripts/zombie_debris.gd`：独立物理刚体，处理重力、碰撞、反弹、摩擦、翻滚、闪白恢复和生命周期。尸体剩余的前臂通过物理肘关节连接，可以随倒地弯折。
- `scripts/demo.gd`：组合场景、四种僵尸的生命界面，以及四条防线死亡 1 秒后独立刷新相同类型新实例的逻辑。
- `scripts/sun_system.gd` / `scenes/pickups/sun.tscn` / `scripts/sun_pickup.gd`：每 10 秒在随机空草坪格上方生成中阳光，垂直下落、固定落地和左键一次性收集；独立管理计时、余额、20 秒落地寿命及 R 重置。
- `scripts/orbit_camera.gd`：模型查看相机的旋转与缩放，默认不启用。

植物的根节点位于地面，炮口朝局部 **+X** 方向。直接把 `peashooter.tscn` 拖入其他 3D 场景即可使用。运行时主要部件的网格、颜色和尺寸由 JSON 应用；未配置的小装饰仍可展开原场景节点编辑。

主场景的结构如下，人物、植物和地形各自独立：

```text
Garden
├── House                  # 独立房屋，正门朝向草坪，含室内、门廊与自动门
├── LawnGrid                 # lawn_grid.tscn 实例
│   └── Tiles
│       ├── Tile_R1_C1       # grass_tile.tscn 实例
│       ├── ...
│       └── Tile_R5_C9       # 共 45 个独立草坪格
├── Plants
│   ├── Peashooter          # peashooter.tscn 实例，第 3 行第 2 列
│   ├── Repeater            # repeater.tscn 实例，第 2 行第 2 列
│   ├── Threepeater         # threepeater.tscn 实例，第 4 行第 2 列
│   ├── GatlingPea          # gatling_pea.tscn 实例，第 1 行第 2 列
│   ├── SnowPea             # snow_pea.tscn 实例，第 5 行第 2 列
│   └── WallNut             # wall_nut.tscn 实例，第 5 行第 8 列
├── Characters
│   └── CrazyDave          # crazy_dave.tscn 实例，朝向 +X
│       ├── Visuals        # 独立可编辑的各部位
│       ├── CollisionShape3D
│       └── WaistMount     # 相对脚底高度 0.94
│           └── Camera3D   # 默认游戏相机，随人物移动与转向
├── Enemies
│   ├── Zombie             # 普通僵尸，第 3 行第 9 列，200 生命
│   ├── ConeheadZombie     # 路障僵尸，第 2 行第 9 列，570 生命
│   ├── BucketheadZombie   # 铁桶僵尸，第 1 行第 9 列，1370 生命
│   └── PoleVaultingZombie # 撑杆僵尸，第 5 行第 9 列，500 生命
├── Projectiles            # 运行时生成的独立豌豆实体
├── Debris                 # 脱落路障/铁桶/长杆、断手、飞头和尸体；独立于活着的僵尸
├── SunSystem              # 掉落计时与余额，子节点为可收集的独立中阳光
├── BackgroundGround       # 草坪外背景地面的物理碰撞
├── WorldEnvironment
├── Sun / SoftFill / Backdrop
└── OrbitRig               # M 切换的模型查看相机
```

草坪在 **X-Z 平面**排列，9 列沿 X 轴、5 行沿 Z 轴；相邻格中心间距为 **2.4**，草皮顶面高度为 **0.025**。格子深浅交错。`Tile_R1_C1` 表示第 1 行第 1 列；脚本接口的 `row` 和 `column` 从 0 开始，`grid_coordinates` 使用 `(column, row)`。

例如 `LawnGrid.cell_to_world(2, 1)` 返回第 3 行第 2 列的种植位置，`get_tile(2, 1)` 返回该草坪实体。植物放在独立的 `Plants` 容器里，僵尸放在独立的 `Enemies` 容器里，可以单独移动或删除，草坪保持完整。当前已经实现豌豆射击和僵尸行走受击；撑杆僵尸会跃过同一路径的第 8 格坚果；尚未实现僵尸啃食植物和交互种植。

## 交战规则

| 项目 | 当前设定 |
| --- | --- |
| 射击条件 | 植物前方、同一条 X 方向防线内，存在存活并着地的陆地僵尸 |
| 射击间隔 | 1.5 秒，发现有效目标后计时；没有目标时停止并重置计时 |
| 双发射手 | 每 1.5 秒开始一次两连射，两颗间隔 0.18 秒，每颗伤害 20；仅检测自己所在行的陆地僵尸 |
| 机枪射手 | 每 1.5 秒开始一次四连射，相邻两颗间隔 0.18 秒，每颗伤害 20，一轮全部命中造成 80 伤害；仅检测自己所在行的陆地僵尸 |
| 三线射手 | 任意覆盖路径出现前方的陆地僵尸时，每 1.5 秒同时向自身及左右相邻路径各发射一颗豌豆，每颗伤害 20；边界行跳过场地外的路径 |
| 寒冰射手 | 自己所在路径出现前方的陆地僵尸时，每 1.5 秒发射一颗寒冰豌豆，伤害 20；命中后减速 50%，持续 10 秒，重复命中刷新持续时间，不叠加减速比例 |
| 撑杆跳跃 | 当前优先遇到第 5 行第 8 列的坚果；靠近同一路径前方第一株植物 1.3 单位时，准备 0.28 秒，然后以重力弹道跃过，默认起跳高度 1.85 单位，落在植物后方约 1.1 单位；每只僵尸只跳一次 |
| 长杆脱落 | 起跳后释放长杆，或在生命 ≤100 失去一只手时松手丢杆；独立刚体落地、碰撞和滚动，10 秒后消失 |
| 植物后坐力 | 每颗豌豆发射后，头部、炮口和整段茎绕根部的共同支点一起后仰；根部与叶片留在原位。默认单次 20°，0.28 秒一起平滑恢复，总后仰不超过 30° |
| 豌豆伤害 | 每颗 20 点，每次碰撞只结算一次，命中后立即消失 |
| 豌豆飞行 | 从炮口水平沿植物前方飞行，默认速度 10 单位/秒，无重力、不追踪 |
| 僵尸生命 | 普通僵尸 200，需要 10 次命中；路障僵尸 570，需要 29 次命中；铁桶僵尸 1370，需要 69 次命中；撑杆僵尸 500，需要 25 次命中 |
| 僵尸移速 | 默认 0.5 单位/秒，缓慢朝向植物走，并保持在原防线上 |
| 受击特效 | 全身网格闪白 0.5 秒，然后恢复当前材质；减速期间呈冰蓝色，减速结束恢复原色，每个实例独立处理 |
| 受击冲击 | 向豌豆飞行方向小幅击退，默认初速度 1.4 单位/秒，衰减速度 10 单位/秒²；60 Hz 物理更新下，单次命中在暂停行走、无遮挡时实测位移约 0.11 单位，相当于 2.4 单位草坪格宽度的 4.58%；同时向后倾斜，最大后仰 30°，0.5 秒恢复 |
| 路障脱落 | 路障僵尸生命 ≤200 时，帽子只脱落一次；向上、向外抛出，落地碰撞和翻滚，脱落后 10 秒消失 |
| 铁桶脱落 | 铁桶僵尸生命 ≤200 时，铁桶只脱落一次；抛物线飞出，独立刚体碰撞、翻滚和摩擦，脱落后 10 秒消失 |
| 随机断手 | 四种僵尸生命 ≤100 时，随机脱落左手或右手及前臂，只掉一边；刚体落地，脱落后 10 秒消失 |
| 击败与倒地 | 生命 ≤0 时，头向上、向外抛出，身体随机向前或向后物理倒地；停止行走与被瞄准，保留最后一次 0.5 秒闪白 |
| 死亡清理 | 尸体及仍连接的前臂在死亡 5 秒后消失；飞出的头在脱落 10 秒后消失 |
| 刷新 | 从生命归零开始等待 1 秒，普通僵尸从第 3 行第 9 列、路障僵尸从第 2 行第 9 列、铁桶僵尸从第 1 行第 9 列、撑杆僵尸从第 5 行第 9 列独立刷新满血同类型新实例；旧尸体、路障、铁桶、长杆、断手和头保留各自的计时 |

射击参数通过 `config/game_config.json` 的 `plants` 调整，生命、移速和击退参数通过 `zombies` 调整，是否刷新与等待时间通过 `respawn` 调整（默认启用、1 秒）；新僵尸继承当前僵尸的战斗参数，生命和受击状态重新初始化。按 R 重新开始会取消待刷新计时，避免多生成僵尸。视觉后仰与角色碰撞体分开处理，保证移动和着地稳定。豌豆使用球形触碰检测，同时沿每帧飞行线段检测碰撞，防止快速穿越目标时漏判。飞出有效距离的豌豆会自动清理。

后续调整击退可修改 `config/game_config.json` 中 `zombies.common.knockback_speed`（初始 1.4，越小距离越短）和 `zombies.common.knockback_deceleration`（初始 10.0，越大停止越快）；后仰使用独立的角度与恢复逻辑。实际位移会受物理步长、障碍碰撞和连续命中影响；上述 0.11 是单次命中的独立击退分量，不包括僵尸自身行走。

五种豌豆植物和坚果都是 `Plants` 下的独立实体。双发射手、机枪射手、寒冰射手和普通豌豆射手分别攻击自己所在行的僵尸。机枪射手每轮按四个炮管的顺序发射，第四颗与第一颗相隔约 0.54 秒；目标失效时取消剩余连射，恢复目标后重新等待完整射击间隔。三线射手当前检测第 3、4、5 行，任意一行存在有效目标便齐射三颗，包括没有僵尸的覆盖路径。豌豆从各自炮口出发，两侧豌豆在水平面内平滑展开，在前进 3.6 单位后对齐相邻路径并直线前行；飞行高度不变，只对各自目标路径的僵尸造成伤害。`plants.types.threepeater.lane_spread_distance` 可在 JSON 中调整展开距离。暂停摆动按钮同时控制五株植物，重新开始会清理所有豌豆、重置五株植物的冷却和姿态，并取消双发射手与机枪射手尚未发出的连射。

五株豌豆植物共用后坐力逻辑，双发射手和机枪射手每颗豌豆都会触发一次，三线射手每轮齐射触发一次共同后坐力。全部头部和整段茎使用同一个根部支点变换，始终保持连接；植物根节点、根部网格和所在格子保持固定，地面叶片不参与开火后仰。机枪射手的头盔和四管炮口随头部一起后仰。豌豆从发射时的炮口位置出发，始终在水平面内飞行。暂停待机摆动不会停止射击后坐力；没有目标时后坐力仍会恢复，按 R 重新开始会立即清除头部和茎的后仰。JSON 的 `plants.common` 或对应 `types` 可调整 `recoil_degrees` 和 `recoil_recovery_time`，运行时也会强制执行 30° 的角度上限。

寒冰减速把僵尸的有效行走速度从 0.5 降为 0.25 单位/秒，并放慢迈腿动作，基础移速参数保持 0.5。JSON 的 `plants.types.snow_pea` 可调整 `slow_multiplier` 和 `slow_duration`。重复命中只刷新计时，普通豌豆不改变已有减速。每只僵尸使用自己的冰蓝色材质副本，闪白优先显示；减速到期、死亡、刷新和重新开始都会清除状态。脱落部件沿用原来的材质与独立闪白恢复，不保留活体的寒冰颜色。

脱落部件与尸体使用 `RigidBody3D`、独立碰撞形状和物理材质，飞行过程中由重力改变速度，落地后的反弹、滚动及停止由碰撞、摩擦和阻尼计算。它们与草坪及其他遗留部件发生物理碰撞，使用独立碰撞层，避免挡住豌豆或被作为存活僵尸检测。尸体、头和断手分开管理，因此 1 秒刷新新僵尸不会提前清理遗留部件。一次大伤害跨过多个阈值时，每个部件依然只生成一次。

疯狂戴夫模型的总高度为 **1.82**（包含锅帽），豌豆射手静止时约 **1.66**，戴夫约高 **10%**。人物场景的正面为局部 **-Z**，在主场景中旋转后与豌豆射手共同朝向世界 **+X**。

僵尸实际模型高度约 **1.82**，与戴夫差不多高。僵尸场景的正面同样为局部 **-Z**，在主场景中旋转后朝向世界 **-X**，与植物相向站立。脚底位于实体原点，放置位置为 `LawnGrid.cell_to_world(2, 8)`。

默认相机是透视相机，直接挂在 `CrazyDave/WaistMount/Camera3D` 下；`dave.waist_height` 默认为 **0.94**，在 JSON 中可调整。戴夫的可视网格使用渲染层 2，腰部相机只看渲染层 1，以免身处人物内部时被衣服遮住。模型查看相机同时显示两个渲染层。人物的碰撞体与地面交互，移动边界包含草坪、房屋和房屋周围的地面。镜头没有挂到头部，也没有通过远处相机模拟腰部视角。

模型由本项目的几何体和原创网格组成，无需外部模型包。`python tools/build_assets.py --cone-only` 只重新生成普通僵尸、路障僵尸和主场景。`--bucket-only` 只重新生成铁桶僵尸与主场景。`--repeater-only` 只重新生成双发射手与主场景，保留已有模型和地形。`--threepeater-only` 只重新生成三线射手与主场景。`--gatling-only` 只重新生成机枪射手与主场景。`--snow-only` 只重新生成寒冰射手、寒冰豌豆与主场景。`--pole-only` 只重新生成撑杆僵尸与主场景。`--nut-only` 只重新生成坚果与主场景。`--zombie-only` 只重新生成普通僵尸与主场景。`--dave-only` 只重新生成戴夫与主场景，保留植物、地形与僵尸。`--layout-only` 只重新生成单格草坪、配置指定的场地（默认 5 × 9）和主场景，保留已有植物、戴夫与僵尸。省略参数会重新生成所有基础网格和场景。手动编辑过对应 `.tscn` 后请勿直接运行生成器，以免覆盖改动。
